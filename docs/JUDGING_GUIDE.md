# Judging Guide

## If you only have 90 seconds

Look for these four things:

1. **Matter, not chat** — multiple conversations/documents/work products live under the same legal Matter.
2. **Evidence return** — legal claims can return to a canonical source/passage instead of a generic reference list.
3. **Work-product continuity** — generated legal documents stay editable in-page with bounded revisions and history.
4. **Scoped collaboration** — trainees, supervisors and client reviewers do not receive the same permissions by default.

## Technical differentiators

### Deterministic legal state boundaries

AI is not the authority for Matter permissions, source identity, approval, action completion, or artifact lineage.

### Professional coverage

Selected professional Skills/Methods/Lenses are not supposed to disappear merely because a model chooses a shorter narrative. Material findings are tracked through a coverage contract.

### Prompt governance

The system separates a lightweight semantic router from professional legal prompts and supports controlled rollout modes rather than replacing all model behavior at once.

## Claims intentionally not made

The showcase does **not** claim that:

- every jurisdiction is fully live-connected;
- all enterprise provider integrations are configured;
- prompt v1 has already proven superiority in live A/B;
- full production smoke has completed;
- external lawyer/user validation has completed.

These are tracked as explicit validation milestones rather than hidden limitations.
