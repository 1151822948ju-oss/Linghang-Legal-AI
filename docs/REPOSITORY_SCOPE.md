# Public Repository Scope

This public repository is designed for competition review and technical/product evaluation.

## Included

- product description;
- architecture diagrams;
- capability and trust model;
- demo/judging guide;
- sanitized public API-contract examples.

## Intentionally Private

- full production source tree;
- owner-approved system prompts;
- domain Worker prompts;
- proprietary Skill/Method/Lens bodies;
- internal evidence/research datasets;
- gold cases and adversarial evaluation fixtures;
- database migrations and full production schemas;
- provider routing internals;
- credentials and infrastructure secrets;
- user/Matter data;
- private deployment configuration.

## Why

The public repository should let reviewers understand the engineering approach without creating a copyable release of the proprietary legal reasoning and production system.

Public interfaces in `public-contracts/` are illustrative, sanitized competition contracts. They are not a source-code mirror of the private repository.
